# Folio 0.3 Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Folio 0.3.0 — outline, find, quick open, folder search, section links; formatting shortcuts, pasted images, word count, crash recovery, autosave; ⋯ menu, zoom, theme, Mermaid, KaTeX, export/print; session restore, sidebar file operations, auto-update.

**Architecture:** Same layering as 0.2: pure logic in small JS modules under `src/desktop/` (node-tested) and Rust in `src-tauri/folio-core` (cargo-tested, no Tauri), a thin Tauri command layer in `src-tauri/src/lib.rs`, and `src/desktop/backend.js` as the only Tauri caller with `fake-backend.js` mirroring every call. `main.js` wires modules; each feature lives in its own module.

**Tech Stack:** existing (Tauri 2.12, CodeMirror 6, marked 18, DOMPurify, highlight.js, esbuild, node:test, jsdom, notify 8). New: `mermaid@^11` and `katex@^0.16` (npm, desktop bundle only, lazy chunks); `trash` (crate, latest 5.x), `base64` (crate 0.22); `tauri-plugin-updater = "2"`, `tauri-plugin-process = "2"`, npm `@tauri-apps/plugin-updater@^2`, `@tauri-apps/plugin-process@^2`.

**Spec:** `docs/superpowers/specs/2026-10-09-folio-0.3-features-design.md` — read the sections your task names; copy strings, sizes, keys and limits from it verbatim.
